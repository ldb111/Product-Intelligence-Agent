## 冻结标注规则

1. **先判断证据资格，再判断业务变化。** 当前介绍、重复宣传、普通修复或仅文案变化，
   可以判断充分时是 no_event；只有版本号而无产品信息、关键历史缺失或冲突时是 uncertain。
2. **Path A** 每个 event 的具体变化项须有同项前后原文。版本号不同不是变化证据；
   当前“新增”不能代替过去状态。不能修改冻结路径以适应答案。
3. **Path B** 官方明确的新能力、调价、商业模式或生命周期声明可以独立证明 event，
   无历史则 previous_state=null。公测不是全面正式上线，预计停止不是已经完成停止。
4. 主类型按实际动作：能力 capability、可用阶段 availability、费用 pricing、套餐/额度
   plan_packaging、访问授权 access_permission、商业版/许可商业模式 commercialization、
   停止支持 deprecation、定位转变 positioning。不能只为覆盖八类而强贴标签。
   新增一个企业版功能以能力为主，只有明确套餐归属调整才是套餐变化。
5. 多项相关能力/费率是同一业务动作的 change_items；真正独立业务动作不能为了单标签
   指标强合并。评分时保留全部预测，不能根据 Gold 挑选命中候选。
6. event 的主题与动作可归纳；两侧状态、范围、日期使用原文。正文不支持的日期、旧状态、
   范围留空。页面发布时间与实际发生时间不同；计划表“预计”日期只能表达计划生效时间。
7. 非 event 事实字段全部为空，uncertain 必须指出缺口。每条 annotation_notes 记录判断
   与可能歧义；不得先查看生产预测再选择主类型或修改答案。

Leakage Guard，再一次性真实运行。来源已冻结，运行时不得补抓网页。禁止 Gold、标注方法、
备注、覆盖目标或分布进入模型输入。仅使用已配置的 DeepSeek / deepseek-flash。

报告分开给出执行成功率、Validated Accuracy、Macro F1、Event Precision/Recall、
End-to-End Correct Rate、Path A/B、类型与有证据日期指标。ERROR/BLOCKED 不从端到端分母删除。
